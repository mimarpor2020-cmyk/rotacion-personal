Cómo aprende

Estado s
Nivel de riesgo que da la red neuronal: bajo, zona de duda o alto.
Acción a
Estrategia de prompt con la que el LLM redacta la recomendación ({{ estrategias|length }} opciones).
Recompensa r
r = (estrellas − 3) / 2: 1★ = −1, 3★ = 0, 5★ = +1.
Política
ε-greedy con ε = {{ n2(p.epsilon) }}: el {{ (p.epsilon * 100)|int }} % de las veces explora una estrategia al azar; el resto usa la de mayor Q.
Actualización
Q(s,a) ← Q(s,a) + α [r − Q(s,a)], con α = máx(1/N, {{ n2(p.alfa_min) }}). Valor inicial optimista Q₀ = {{ n2(p.q_inicial) }} para que pruebe todas las estrategias.
Memoria
Los comentarios de las recomendaciones bien y mal valoradas se incluyen en el siguiente prompt de esa misma estrategia.

Valor aprendido de cada estrategia
